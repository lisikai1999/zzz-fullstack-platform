# ZZZ Fullstack Platform

A full-stack web platform with frontend and backend.

## Project Structure

```
zzz-fullstack-platform/
├── frontend/     # Vue 3 + Vite frontend
├── backend/      # Express.js backend
└── README.md
```

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
